# DevSwitchboard License Intent Update

**Decision ID:** `DEC-LICENSE-001`
**Task:** `devswitchboard-bootstrap-001`
**Revision:** 1
**Status:** Approved
**Owner:** Developer
**Derived from:** Approved Handoff revision 1

## Decision

DevSwitchboard uses the Apache License 2.0.

## Rationale

DevSwitchboard is intended to evolve from a documentation-first open-source methodology into tooling that may later include CLI, skills, plugins, adapters, and other executable components. Apache-2.0 is a permissive open-source license with an explicit patent grant suitable for that direction.

## Routing correction

The initial bootstrap classified OSS license selection as an implementation adaptation. That classification was a router error: licensing is a developer-owned legal and distribution decision.

If a decision changes licensing, legal terms, publication policy, ownership, or material distribution rights, DevSwitchboard MUST classify it as intent and MUST require developer approval. The rule is semantic and does not prescribe a particular license.
